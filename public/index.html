Disaster-response communication

Messages that get through when the internet doesn't.

Relay-Mesh turns every phone and laptop into a relay. Messages hop device to device over Bluetooth and WebRTC, stay end-to-end encrypted, wait in a store-and-forward buffer when nobody is in range, and put SOS calls on a live map.

Features

Mesh routing

Controlled flooding (gossip) with hop limits (TTL), unique packet ids for duplicate suppression and a full route trace on every message.

Store and forward

Every node carries packets in IndexedDB and hands them to each new neighbour it meets (epidemic routing). Acks immunise the network so delivered messages stop spreading.

End-to-end encryption

ECDH P-256 key agreement and AES-256-GCM through the Web Crypto API. Relays forward ciphertext they cannot read; headers are bound as authenticated data.

SOS broadcast

One tap shares GPS position and a note with every reachable node. Alerts appear as pins on a live Leaflet map, with an extended hop limit.

Live topology

Nodes exchange link-state adverts every few seconds, so each device builds its own map of the network and animates packets as they move.

Command dashboard

A base station view of every node: links, round-trip times, hop counts, relays, duplicates and SOS alerts in real time.

Packet format

{
  "id": "9f2c1a...",          // unique id, used for duplicate suppression
  "type": "dm",               // lsa | chat | dm | sos | ack
  "src": "a1b2...", "dst": "c3d4...",   // "*" for broadcast
  "ttl": 7,                   // decremented on every hop
  "hops": ["a1b2", "e5f6"],   // route trace
  "payload": { "iv": "...", "ct": "...", "pub": {...} }  // ciphertext only
}

Demo with one laptop and one phone

  1. Start the server on the laptop (npm start) and open /app.html in three browser tabs. Each tab is a separate node with its own keys.
  2. Scan the QR code printed in the terminal with your phone (same Wi-Fi or the phone's hotspot) to add it as a node.
  3. Open the dashboard on the laptop to watch the topology form.
  4. Multi-hop: on node A, open Network and click Cut link to node C. Send C an encrypted DM. It is routed A → B → C, and the ack shows the hop count and round-trip time.
  5. Store and forward: turn on Airplane on C, send it a DM from A, then turn Airplane off. The carried message is delivered when C reappears.
  6. SOS: on the phone, open SOS Map and tap Send SOS. Watch the pin appear on every node and on the dashboard.
